# Terra Week 1
A Terminal Based Monster Fighter.
You fight a monster using the terminal in a pokemon-style battle. The game ends when one of you runs out of health.
# Moves
You have 3 moves, bonk, boom, and swipe
Swipe has 4 uses after that you have to use other moves
Boom skips your next turn
Bonk has no restrictions, but it is weak
# Attacking
The game asks for a prompt in the terminal, you have to write the move you want to use
no spaces, any capitalization
